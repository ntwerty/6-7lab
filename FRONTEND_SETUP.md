# Настройка фронтенда

## Быстрый старт с Docker

Фронтенд автоматически собирается и запускается при выполнении `docker-compose up --build`.

## Локальная разработка

Если вы хотите разрабатывать фронтенд локально без Docker:

### 1. Установите зависимости

```bash
cd frontend
npm install
```

### 2. Настройте переменные окружения

Создайте файл `frontend/.env`:
```
REACT_APP_API_URL=http://localhost:8000/api
```

### 3. Запустите dev сервер

```bash
npm start
```

Фронтенд будет доступен на http://localhost:3000

### 4. Убедитесь, что бэкенд запущен

Бэкенд должен быть доступен на http://localhost:8000

## Структура компонентов

### Страницы
- `Home.js` - Главная страница
- `Login.js` - Страница входа
- `Register.js` - Страница регистрации
- `Game.js` - Игра Арканоид
- `Profile.js` - Профиль пользователя
- `Leaderboard.js` - Таблица лидеров
- `Achievements.js` - Достижения
- `Friends.js` - Система друзей

### Компоненты
- `Navbar.js` - Навигационное меню
- `PrivateRoute.js` - Защищенный маршрут

### Контексты
- `AuthContext.js` - Контекст аутентификации

### Сервисы
- `api.js` - Axios клиент для API запросов

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `build/`, которые затем используются в Docker образе с Nginx.

## Особенности реализации

### Игра Арканоид
- Реализована на Canvas API
- Автоматическое сохранение каждые 30 секунд
- Три уровня сложности
- Система жизней
- Прогрессия уровней

### Аутентификация
- JWT токены с автоматическим обновлением
- Хранение токенов в localStorage
- Автоматический редирект на логин при истечении токена

### API интеграция
- Все запросы через axios
- Автоматическая обработка ошибок
- Интерцепторы для токенов
