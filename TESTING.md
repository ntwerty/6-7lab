# Руководство по тестированию

## Автоматические тесты

### Запуск всех тестов

```bash
python manage.py test
```

### Запуск конкретного модуля тестов

```bash
# Тесты моделей
python manage.py test game_app.tests.test_models

# Тесты сериализаторов
python manage.py test game_app.tests.test_serializers

# Тесты представлений
python manage.py test game_app.tests.test_views

# Тесты аутентификации
python manage.py test game_app.tests.test_auth

# Интеграционные тесты
python manage.py test game_app.tests.test_integration

# Тесты админки
python manage.py test game_app.tests.test_admin

# Тесты безопасности
python manage.py test game_app.tests.test_security
```

### Запуск конкретного теста

```bash
python manage.py test game_app.tests.test_models.UserModelTest.test_create_user
```

### Запуск с подробным выводом

```bash
python manage.py test --verbosity=2
```

### Запуск тестов с покрытием кода (требует coverage)

```bash
# Установка coverage
pip install coverage

# Запуск тестов с покрытием
coverage run --source='.' manage.py test

# Просмотр отчета
coverage report

# HTML отчет
coverage html
```

## Инструкции по ручному тестированию

### Тестирование регистрации и входа

1. Откройте страницу регистрации
2. Попробуйте зарегистрироваться с валидными данными
3. Проверьте, что регистрация прошла успешно
4. Попробуйте зарегистрироваться с невалидными данными (несовпадающие пароли, слабый пароль)
5. Проверьте, что отображаются соответствующие ошибки
6. Войдите с созданными учетными данными
7. Проверьте, что вход прошел успешно

### Тестирование игровой сессии

1. Войдите в систему
2. Создайте игровую сессию через API или интерфейс
3. Проверьте, что сессия сохранилась
4. Проверьте, что профиль пользователя обновился (games_played увеличился)
5. Проверьте, что достижения были выданы (если условия выполнены)
6. Проверьте, что запись появилась в таблице лидеров (если игра завершена)

### Тестирование системы друзей

1. Создайте двух пользователей
2. Отправьте запрос в друзья от первого пользователя второму
3. Проверьте, что запрос создан со статусом "pending"
4. Примите запрос от имени второго пользователя
5. Проверьте, что статус изменился на "accepted"
6. Создайте вызов между друзьями
7. Проверьте, что вызов создан

### Тестирование админ-панели

1. Войдите как администратор
2. Откройте админ-панель
3. Проверьте, что все модели доступны
4. Выберите несколько игровых сессий
5. Экспортируйте их в XLSX
6. Проверьте, что файл создан и содержит правильные данные
7. Проверьте структуру файла (заголовки, данные)

### Тестирование безопасности

1. Попробуйте получить доступ к данным другого пользователя
2. Проверьте, что доступ запрещен
3. Попробуйте использовать SQL-инъекцию в поисковом запросе
4. Проверьте, что инъекция не сработала
5. Попробуйте использовать XSS в поле bio
6. Проверьте, что данные экранируются при выводе

### Тестирование адаптивности

1. Откройте приложение на ПК
2. Проверьте отображение всех страниц
3. Откройте приложение на планшете (или используйте инструменты разработчика браузера)
4. Проверьте отображение всех страниц
5. Откройте приложение на смартфоне (или используйте инструменты разработчика браузера)
6. Проверьте отображение всех страниц
7. Убедитесь, что элементы не перекрываются и текст читаем
