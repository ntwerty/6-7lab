# 🎮 Быстрый старт - Игра Арканоид

## 🚀 Запуск всего проекта за 3 шага

### Шаг 1: Настройка окружения

Создайте файл `.env` в корне проекта:
```bash
cp .env.example .env
```

Отредактируйте `.env` при необходимости (по умолчанию настройки подходят для Docker).

### Шаг 2: Запуск всех сервисов

```bash
docker-compose up --build
```

Эта команда запустит:
- ✅ PostgreSQL базу данных
- ✅ Django backend (API)
- ✅ React frontend (игра)

### Шаг 3: Создание администратора

В новом терминале:
```bash
docker-compose exec web python manage.py createsuperuser
```

## 🌐 Доступ к приложению

После запуска откройте в браузере:

- **🎮 Игра (Frontend)**: http://localhost:3000
- **🔧 API (Backend)**: http://localhost:8000/api/
- **⚙️ Admin панель**: http://localhost:8000/admin/

## ❓ Проблемы?

### Порт уже занят
Если порты 3000 или 8000 заняты, измените их в `docker-compose.yml`:
```yaml
ports:
  - "3001:80"  # вместо 3000:80
  - "8001:8000"  # вместо 8000:8000
```

### Ошибки при сборке
Попробуйте:
```bash
docker-compose down -v
docker-compose up --build
```

### База данных не подключается
Убедитесь, что PostgreSQL контейнер запущен:
```bash
docker-compose ps
```
